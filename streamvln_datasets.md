| Dataset / Data Source      | Type                                 | Scene Source                     |                            Scale in StreamVLN | Main Role in StreamVLN                                                                      |
| -------------------------- | ------------------------------------ | -------------------------------- | --------------------------------------------: | ------------------------------------------------------------------------------------------- |
| **Matterport3D / MP3D**    | 3D indoor scene dataset              | Real scanned indoor environments | 60 MP3D environments used for navigation data | Provides realistic indoor 3D environments for R2R, RxR, and EnvDrop navigation trajectories |
| **HM3D**                   | Large-scale 3D indoor scene dataset  | Habitat-Matterport 3D scenes     |           700 HM3D scenes via ScaleVLN subset | Increases scene diversity and improves generalization to unseen environments                |
| **R2R / Room-to-Room**     | VLN instruction-following dataset    | MP3D                             |       Included in 450K navigation video clips | Provides English language instructions and expert navigation paths                          |
| **RxR / Room-Across-Room** | Multilingual VLN dataset             | MP3D                             |       Included in 450K navigation video clips | Provides longer, more diverse, multilingual navigation instructions                         |
| **R2R-EnvDrop / EnvDrop**  | Augmented VLN trajectory data        | MP3D                             |       Included in 450K navigation video clips | Expands R2R-style navigation supervision and improves robustness                            |
| **ScaleVLN subset**        | Large-scale VLN trajectory data      | HM3D                             |        300K samples / about 150K trajectories | Adds large-scale navigation data from more diverse HM3D scenes                              |
| **DAgger data**            | Corrective navigation demonstrations | Habitat simulator                |                                  240K samples | Teaches the model to recover from its own navigation errors during closed-loop rollout      |
| **LLaVA-Video-178K**       | General video instruction / VQA data | General video sources            |                      Part of 248K VQA samples | Preserves video understanding and temporal reasoning ability                                |
| **ScanQA / SQA3D**         | 3D question answering data           | ScanNet                          |                      Part of 248K VQA samples | Enhances 3D spatial reasoning, object grounding, and geometric understanding                |
| **MMC4**                   | Interleaved image-text data          | Web image-text documents         |                                  230K samples | Improves multi-turn interleaved vision-language reasoning                                   |
